Cómo realizar un cambio

  1. Con el robot elevado, en INITIAL o con el área despejada, pulsa Recargar.
  2. Modifica uno o varios valores. Esto sólo cambia el formulario: todavía no configura ni mueve el robot.
  3. Pulsa Aplicar en vivo para probar. Se aplica al brain actual, pero se pierde al reiniciar.
  4. Cuando el resultado sea seguro, pulsa Aplicar y guardar. Se aplica ahora y también en próximos arranques.

Importante: aplicar cualquiera de las dos opciones puede cambiar el movimiento inmediatamente si el robot está en un estado activo.

01

Modo original del demo

El comportamiento conocido originalmente es mode=attack, kick.type=default y prediction.enabled=false.

Este botón sólo prepara el formulario. Para completar la restauración debes pulsar Aplicar y guardar.

02

Cambiar la patada

En Patada, usa default para Kick convencional o visual para RLVisionKick. Los ajustes del tipo no seleccionado se conservan, pero no se ejecutan.

03

Activar el predictor

Activa prediction.enabled y mantén require_localization=true. Primero valida muestras y trayectoria con el robot elevado.

Qué parte del robot afecta cada grupo

READY y coberturaPosición del cuerpo frente a la portería, velocidad longitudinal/lateral y giro.

PersecuciónMarcha hacia el balón cuando el modo attack decide reclamarlo.

Ajuste y posesiónPasos cortos, rodeo y alineación antes de despejar.

CámaraMovimiento de cabeza, rapidez del seguimiento y patrón de búsqueda.

PatadaSelección y ejecución del despeje convencional o VisualKick.

PredicciónCalcula y decide si existe un tiro; sus umbrales no mueven por sí solos.

Bloqueo predictivoMovimiento del cuerpo al punto lateral previsto cuando la decisión es block_shot.
