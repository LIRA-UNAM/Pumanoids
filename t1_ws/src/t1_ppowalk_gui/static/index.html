Velocity command

Sent to the policy while it runs (cmd_vx / cmd_vy / cmd_wz). Drag a joystick to command, release to stop; full deflection reaches the limits in the Policy tab.

With the remote as source: left stick front/back = forward/back (vx), left/right = sideways (vy); right stick left/right = turn (wz). Full deflection reaches the velocity limits; inside the deadzone the command is exactly 0. START (+) runs the same Start as the button above, with the same checks (robot upright within the max tilt, leg motors healthy, fresh data, model loaded). BACK (−) runs Home (it also stops a running policy).

Calibration offsets

Added to the command to cancel the robot's drift (e.g. a negative vy offset if it walks slightly left when going straight). Applied only while motion is commanded unless the checkbox is set; the sum is clamped to the limits.
